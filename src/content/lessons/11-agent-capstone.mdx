## 最终验收

不要新建一个演示项目。选择入门阶段已经上线并获得反馈的产品，用工程方法解决一个真实改进。

仓库必须包含：简洁的项目级 Agent 指令、决策完备的功能规格、可逐步执行的计划、至少一个经过真实任务验证的 Skill、自动测试、评审记录和部署检查表。

## 完成交接实验

清空当前会话，让新的 Agent 只读取仓库。它应能说明项目目标、运行验证、找到当前规格并继续一个小任务。记录它提出的歧义；这些歧义就是文档或边界仍需改进的位置。

## 证据包

1. 用户问题与本次改进的证据。
2. 规格、计划及范围外事项。
3. 失败测试、最小实现、全量验证输出。
4. 规格评审与质量评审的修正记录。
5. 公开部署、回滚方式与交接实验结果。

当另一位开发者或 Agent 能依据这些证据重复你的过程，你掌握的就不再只是 Vibe Coding，而是可持续的 Agent 工程。
